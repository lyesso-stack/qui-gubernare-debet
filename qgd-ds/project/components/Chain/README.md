# Chain

La chaîne de traçabilité de l'euro, en 8 maillons, de la loi de finances jusqu'aux factures. Chaque maillon a un état (Status).

- Le trait entre deux maillons est plein si le suivant est traçable, pointillé `cut` ou `no` sinon.
- L'ordre et le nombre des maillons ne changent pas d'une page à l'autre.
