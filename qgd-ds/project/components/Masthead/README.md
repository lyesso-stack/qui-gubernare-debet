# Masthead

Le bandeau du haut de chaque page : une ligne navy qui dit « Site citoyen indépendant », puis l'en-tête blanc avec le sceau, le nom et la navigation.

- Fournir : le lien actif (`aria-current="page"`), la date des données.
- Le bouton « Demander les pièces » est le seul bouton principal de l'en-tête.
- Ne jamais y mettre de drapeau, de Marianne ni les mots « République française » : le site n'est pas l'État.
