# PageHead

Le bandeau navy de titre de page : fil d'Ariane, libellé en capitales, titre en `display`, chapeau, puis 2 à 4 chiffres clés.

- Une fois par écran, juste sous le Masthead.
- Chaque chiffre porte sa source en dessous (`qg-src`). Un chiffre sans source n'entre pas.
- Le titre est une phrase vraie, pas un slogan : « Où vont 448,3 milliards d'euros ».
