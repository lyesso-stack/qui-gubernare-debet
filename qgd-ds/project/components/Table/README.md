# Table

Le registre des contrats : en-tête `paper-sunk` en capitales, montants alignés à droite en tabular-nums, ligne cliquable vers la fiche.

- Sous chaque intitulé, l'acheteur en `ink-3` ; sous chaque titulaire, son SIRET en `code`.
- Une offre unique s'affiche avec l'étiquette `cut` « 1 seule ».
