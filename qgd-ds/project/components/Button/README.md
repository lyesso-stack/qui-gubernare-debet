# Button

Trois genres : **principal** (blue, une fois par vue, pour l'acte que la page sert), **secondaire** (bord `line-control`), **discret** (lien souligné).

- Verbe d'abord, sans point final : « Demander les pièces », « Copier la lettre ».
- `qg-btn-sm` dans les barres de filtres et l'en-tête.
